## 分数数据口径与修复记录（重要）

Word 宝典里"已录取人员初试成绩最高/最低分"部分章节有矛盾（如东北大学控制工程本部：
录取最高 400、最低 399、平均却 421.7）。已按以下口径修复：

- 录取均分：优先取分数段表"总计"行的总分均分（经验证即录取名单初试均分），
  并校验必须落在 [录取最低, 录取最高] 区间内，否则回退到分数段边界或置空
- 复试均分：取"进入复试人员初试成绩平均分"行
- 专业课/数学均分：取分数段表"总计"行的对应均分（两种表格布局已自适应，
  有/无"复试人数"列均支持）
- **学校级录取均分/专业课均分：Σ(各方向录取人数 × 该方向均分) ÷ 总录取人数**
  （严格按录取人数加权，已与手算逐校核对一致）
- 录取人数优先取"实际录取X人"，其次分数段总计行，再次分数段逐段求和；
  紧凑格式（如厦门大学"一志愿进入复试14人，实际共录取7人…复录比1:2"）已兼容
- 缺失分数用 `zexiaobao_data.js`（parquet 个人分数）补全
- 初试分合理性过滤（100-500 分），解析拼凑值（如 4185）自动置空
- 修复后：录取均分越界记录 0 条；电子科大、清华等此前空值的学校已补全
- **首页 131 所学校录取均分全部补齐（0 缺失）**：宝典存在多种分析段格式，解析器现已兼容
  ①标准（东北大学式）②仅录取（电子科大式）③紧凑单行（厦门大学式）
  ④"录取情况/分析"换行+转置表（上海交大式）⑤"…录取情况"无分析后缀（北航式）
  ⑥列式转置表（沈阳工业式）⑦个人分数列表（四川大学式）
- **首页"学院数"补齐**：宝典的学院列表有"逐行/带顿号/带代码（含校区形式）"多种写法，
  解析器已兼容；131 所中仅西安建筑科技大学（宝典未写学院）为 0
- **专业课/数学均分补齐**：无"总计"行的分数段表改用"分数段 × 人数加权"计算各科均分，
  缺口从 197 降至 70；剩余 70 段为宝典本身没有各科均分的数据（如仅录取/紧凑段落），
  详情页如实显示"-"

说明：仍有约 130 条记录（多为"学科介绍有、录取分析无"的兜底记录）录取均分为空，
页面显示"-"；部分学校（如电子科大）宝典明确没有进复试数据，进复试列为空属正常。
