🧭大三前：就业方向怎么选？

  3. 目标城市？一线城市机会多压力大，二线城市性价比高但选择少
  4. 对代码有没有基本的热爱？如果一点都不喜欢，没必要强迫做程序员

💼第一份实习通关指南
⚠️ 第一份实习不是找"最好的"，而是"尽快找到第一个"——有了第一个，第二个第三个会容易很多。
① 简历怎么写？
  1. 一页纸原则：校招简历 1 页足够，HR 平均只看 6 秒
  2. 倒序排列：最近经历放在最前面
  3. STAR 法则写项目：Situation（背景）→ Task（你承担的任务）→ Action（做了什么，动词开头）→ Result（结果、数据、获奖）
    ❌ "做了一个嵌入式项目"
    ✅ "主导设计了基于 STM32 的智能垃圾分类系统，独立完成 PCB 原理图与焊接、FreeRTOS 多任务调度、通过红外传感器实现分类准确率 92%，获校电子设计竞赛一等奖"
  4. 量化一切：用数字体现规模、效果、速度、效率提升
  5. 技能部分真实可被拷问："熟练"/"精通"一定要配项目佐证
② 简历没有项目怎么办？（半年冲刺方案）
  • 嵌入式：STM32 + FreeRTOS 做一个智能家居 / 智能车 / 机器人项目（B站教程 100+）
  • 软件转码：用 Spring Boot / React 做 1 个完整 Web 项目（部署到云服务器上，能直接访问）
  • 算法方向：LeetCode 中等题 200+，简历里直接写"ACM 刷题 x 道"附上 GitHub 仓库链接
  • 硬件 / FPGA：完成 1 个简单的 CPU 核心或 UART/I2C 控制器 IP 设计，仿真过
③ 投递策略
  • 实习岗位 11 月开始招（寒假实习）、3 月集中爆发（暑期实习）
  • 渠道：BOSS 直聘 / 实习僧 / 牛客网 / 公司官网校招页 / 学长学姐内推（内推通过率最高）
  • 海投策略：第一阶段广撒网 50+ 份（练面试手感）→ 第二阶段重点投 20 份（意向公司）→ 第三阶段收尾 3-5 offer 对比
  • 不要因为觉得自己不够好就不敢投递——"敢投"本身就是一种竞争力。
🏢企业怎么选？
电子信息类 5 大就业方向 + 代表企业
  1. ① 互联网 / 软件
    字节跳动腾讯阿里百度 美团京东拼多多
    特点：薪资最高（20-40w+），加班强度大，35 岁危机真实存在。岗位：后端开发、前端、客户端、测试、算法。
  2. ② 通信 / ICT 设备商
    华为中兴爱立信诺基亚 新华三紫光
    特点：专业对口度最高，技术积累扎实，海外出差机会多。
  3. ③ 半导体 / 芯片
    海思长鑫存储长江存储 紫光展锐兆易创新韦尔
    特点：国家战略行业，近年薪资大涨，硕士学历起步岗位多。岗位：数字 IC、模拟 IC、验证、后端、封装测试。
  4. ④ 研究所 / 国企 / 军工
    中电科 CETC（14/28/38/54 所） 航天科技 / 航天科工 中国电建 / 国家电网 三大运营商（移动/联通/电信）
    特点：稳定、福利好、户口优势；通常需要硕士及以上，笔试面试流程长。
  5. ⑤ 其他方向
    • 消费电子（小米 OPPO vivo 大疆）、汽车电子（比亚迪 蔚来 理想）、医疗器械（迈瑞）、光电显示（京东方 TCL）
    • 技术销售 / 产品经理（技术背景 + 沟通能力，薪资天花板高）
    • 体制内（公务员 / 选调 / 事业编 / 军队文职）
🎓读研深造完整指南
保研 vs 考研：选择路径
  • 保研：成绩专业前 10-15%（具体比例各校差异大）→ 大三暑假参加夏令营 / 预推免 → 9 月推免系统填报录取
    优点：不用参加统一笔试、选择更多、可以同时面多所院校
    前提：高 GPA + 一定科研/竞赛/论文经历（夏令营筛选很卷）
  • 考研：12 月全国统考（政治 + 英语 + 数学 + 专业课）→ 次年 2-3 月复试
    优点：不看本科绩点（只要能过线）、给逆袭机会
    难点：备考 1 年时间长、竞争激烈、目标院校信息不透明、复试有不确定性

📅秋招 / 春招完整时间线
  1. 大三寒假 / 3-4月：暑期实习提前批：大厂（阿里/腾讯/字节/华为）启动暑期实习，投了不亏，能转正的话秋招压力骤减
  2. 6-7月：实习 + 暑期：暑期实习中好好表现争取 return offer；同时开始打磨简历，刷算法题 / 八股文
  3. 8月：秋招提前批：互联网公司陆续开放提前批，先投先面，部分岗位提前批招满了正式批就不招了
  4. 9-11月：秋招主战场：全国所有企业大规模宣讲、笔试、面试。9月最密集，错过再等一年。同时还有国考（11月底）
  5. 12月：收尾 + 考研：考研党冲初试；已工作党拿到 offer 后可以开始谈薪比价、拒绝不合适的
  6. 次年 3-5月：春招补招：考研失败同学主战场；补招岗位少但捡漏机会多；省考在这个时间
💡 金九银十是秋招关键期。9 月还没投简历的同学，10 月机会大幅缩水。尽早准备！
