大二规划 & 进阶提升指南
专业课攻坚 + 实验室 & 竞赛 + 技能树 + 暑假高质量安排
🎯大二该干什么？
🌱 大二是大学的分水岭：从通识课转向专业课、从被动学习转向主动探索，开始为未来方向（保研/考研/就业）打地基。
大二核心任务清单
  1. 稳住并提升 GPA：大二专业课开始进入培养方案，学分重、对排名影响大，是大二最优先的事
  2. 选定细分方向：硬件 / 软件 / 算法 / 通信 / IC / 光电…… 通过专业导论课、实验室体验、学长访谈，确定 1-2 个方向深入
  3. 进入实验室 / 课题组：大二上学期就可以主动联系导师，从打杂、文献调研开始，争取参与项目或竞赛
  4. 主攻 1-2 个学科竞赛：电赛（省赛）、蓝桥杯、数学建模、智能车…… 至少产出 1 个完整项目，能写进简历
  5. 过六级 + 考计算机二级：六级是保研夏令营和很多大厂的硬门槛，越早过越安心
  6. 开始接触开源 / GitHub：电信类同学建议从大二开始建 GitHub 仓库，记录学习笔记、项目代码，逐步积累作品集
大二避坑提醒
⚠️ 大二最容易陷入两个极端：①「躺平派」松懈导致 GPA 下滑，后期保研/考研被动；②「瞎忙派」什么比赛都报，每个都浅尝辄止，没有产出。聚焦比广撒网更重要。
📘专业课攻坚策略
电信类大二典型专业课
电路分析基础 模拟电子技术（模电） 数字电子技术（数电） 信号与系统 单片机原理 电磁场与电磁波 概率论与数理统计 高频电子线路
硬核课程攻克方法
  1. 模电 / 数电：电路分析是前置，郑益慧模电、王红数电（B站）几乎是公认入门标配；课后务必动手做实验，理论+实操结合才不抽象
  2. 信号与系统：考研核心课之一，西电郭宝龙视频 + Oppenheim 教材课后题，公式推导自己推一遍比看十遍有效
  3. 单片机：从 STM32 / 51 入门，跟着 B站「江科大」「正点原子」做一个小项目（智能车 / 温湿度计 / 蓝牙控制灯），比单纯听课学得快
  4. 电磁场：数学要求高（矢量分析、场论），谢处方教材 + 石群视频，配合 MATLAB 仿真理解抽象概念
  5. 概率论：AI / 通信方向的基础，考研数一必考，大一高数没学好的同学务必补回来
💡 大二专业课难度陡增，不要单打独斗：组 2-3 人学习小组、找研究生学长答疑、参加学院助教辅导，效率提升明显。
🔬实验室 & 竞赛深度参与
如何进实验室？
  1. 选方向：通过专业导论课、学院官网导师主页、师兄师姐打听，圈定 3-5 位方向感兴趣的导师
  2. 邮件自荐（最通用）：
    邮件模板要点：姓名 / 年级专业 / GPA（高就写）/ 已学相关课程和技能（如 C 语言、STM32、Python）/ 为什么对老师方向感兴趣 / 附简历或成绩单 / 表达愿意从基础工作做起
  3. 面试 / 面谈：导师通常会约聊一次，了解你的动机和基础，诚实回答、展示学习能力，不会的不要装会
  4. 从打杂开始：文献调研、数据标注、PCB 焊接、设备调试是正常起步，先证明靠谱再争取核心任务
  5. 每周固定时间到岗：哪怕 4-6 小时，比偶尔泡一天更有价值，建立存在感
大二可冲击的竞赛
竞赛时间难度建议
全国大学生电子设计竞赛（省赛）7-8 月★★★★电赛偶数年为国赛，奇数年省赛；大二组队练手最佳
蓝桥杯4 月★★★算法类入门赛事，C/C++/Java/Python 任选，省奖较容易

智能车竞赛（飞思卡尔）暑期★★★★★嵌入式硬核赛事，备赛周期长，适合硬件方向同学
光电设计竞赛暑期★★★光电方向对口，门槛相对友好
互联网+ 创新创业大赛4-10 月★★★商业计划书+路演，保研加分项
🎯 一个项目海投多赛：做出 1 个完整系统（如智能车 / 物联网设备），可以同时投电赛、互联网+、光电赛，拿 2-4 个奖项性价比极高。
🛠️技能树 & 作品集搭建
电信类大二该会的技能
🔧 硬件方向
• 熟练使用万用表 / 示波器 / 焊接
• Altium Designer / KiCad 画原理图和 PCB
• STM32 / 51 单片机裸机开发
• FreeRTOS 入门
• Verilog / FPGA 基础（IC 方向）
💻 软件/算法方向
• C/C++ 熟练，Python 入门
• 数据结构与算法（LeetCode 100+）
• Linux 基本命令 + Git
• 至少 1 个完整项目部署上线
• 数学（线代/概率/最优化）补强
📡 通信/信号方向
• MATLAB 仿真熟练
• 信号与系统、通信原理吃透
• Python 数字信号处理
• SDR（软件无线电）动手实验
🔬 科研方向
• 文献检索（知网/IEEE/Google Scholar）
• LaTeX 论文排版
• Zotero / EndNote 文献管理
• 复现 1 篇经典论文的实验
建立个人作品集
  • GitHub 仓库：每个课程作业、竞赛项目、学习笔记都建一个 repo，README 写清楚做了什么、怎么用
  • 个人博客：Hexo / Hugo / Notion 公开页面，记录学习心得和踩坑笔记，保研复试和求职面试加分项
  • 视频作品：B 站发项目演示视频，比简历上的文字描述有说服力 10 倍
🔄分流 & 转专业最后窗口
大类招生：大二结束专业分流
  • 分流依据：通常是大一+大二 GPA + 志愿顺序，热门方向（如 AI、IC）竞争激烈
  • 策略：成绩好的同学可以冲热门；成绩中游的同学建议选志愿优先级而非盲目冲，避免被调剂到完全不感兴趣的方向
  • 提前了解：参加学院的专业介绍会，找已分流的学长聊各方向的真实学习内容和就业情况
转专业最后机会
⚠️ 大二下学期通常是转专业的最后窗口。如果大一没转成功、大二仍想转：
  • 提前确认目标专业的转入名额和要求（部分专业大二不再接收转专业）
  • 补齐目标专业大一未修的核心课，否则转过去后课业压力陡增
  • 学分转换评估要提前找教务处沟通，避免延毕
☀️暑假怎么过？
大二暑假三种高质量选择
  1. 留校做竞赛 / 科研（最推荐）：
    • 暑期是电赛、智能车的备战黄金期，集中 1-2 个月能产出全年最好的项目
    • 留在实验室跟导师做科研，争取署名论文或专利
  2. 找第一份实习：
    • 大二暑假可以尝试投递小公司实习或大厂的暑期实习提前批
    • 不要嫌公司小，第一份实习的意义是积累简历素材和职场认知，不是直接拿 offer
    • 渠道：BOSS 直聘、实习僧、学长内推
  3. 系统学习一项硬技能：
    • 暑假完整学完一门慕课（如吴恩达机器学习、CS50、正点原子 STM32 全集）
    • 刷完一本经典教材（如《C Primer Plus》《信号与系统》Oppenheim）
💡 不要整个暑假躺平——大三开学你会发现暑假认真过的同学已经拉开了明显差距。
