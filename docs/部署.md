# 服务器部署指南

> 适用：kaoyan-site 全静态站点 + 录取数据库查询 API。
> 当前后端为 `serve.py`（Python 标准库，零框架依赖），数据库支持 SQLite / MySQL 切换。

## 一、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Linux（Ubuntu 20.04+ / CentOS 8+） |
| Python | 3.9+（建议 3.11） |
| MySQL | 8.0+（使用 SQLite 可跳过） |
| 依赖 | `pip install -r requirements.txt` |
| Web 服务器 | Nginx（推荐，用于反向代理和 HTTPS） |

## 二、上传代码与安装依赖

```bash
# 1. 把仓库 clone 到服务器（或通过 FTP / rsync 上传）
git clone https://github.com/Remikacwz/Kongzhi-ZeXiao-website.git
cd Kongzhi-ZeXiao-website

# 2. 安装 Python 依赖
python3 -m pip install -r requirements.txt
```

## 三、配置数据库

### 方案 A：继续使用 SQLite（小流量、单机足够）

无需改动，默认 `数据库/config.json` 中 `db_type` 为 `sqlite`。
注意：SQLite 模式下导入数据时需要写权限，备份直接复制 `数据库/admission.db` 即可。

### 方案 B：切换 MySQL（推荐上线使用）

1. 建库建表：

```bash
mysql -u root -p < 数据库/schema_mysql.sql
# schema_mysql.sql 会创建 kaoyan_admission 库及 schools / majors / admissions 三张表
```

2. 修改 `数据库/config.json`：

```json
{
  "db_type": "mysql",
  "mysql": {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "改成你的MySQL密码",
    "database": "kaoyan_admission",
    "charset": "utf8mb4"
  }
}
```

3. 导入录取数据：

```bash
# 确保最新 Excel 已放在 数据库/raw/27考研择校宝典_录取数据表_0815.xlsx
python3 数据库/import_admission.py --mysql --host 127.0.0.1 --user root --password "你的密码" --database kaoyan_admission
```

> 专业课科目 / 参考书数据在 `数据库/raw/subjects_books_raw.json`，目前由 SQLite 导入脚本维护；
> MySQL 上线时如需查询页 API 化，请同步把 `exam_subjects` / `reference_books` 导入 MySQL（见 `数据库/schema_mysql.sql` 中的对应表）。

## 四、启动服务

### 开发 / 小流量

```bash
python3 serve.py 8767
# 监听 0.0.0.0:8767；无缓存头已内置，修改 HTML/CSS 刷新即可
```

### 设置后台导入鉴权（上线必做）

```bash
export KAOYAN_ADMIN_TOKEN="你的强随机密码"
python3 serve.py 8767
```

- 未设置 Token：仅允许 127.0.0.1 / ::1 / localhost 访问导入接口。
- 设置 Token 后：`POST /api/admin/import-admission` 必须携带请求头 `X-Admin-Token`。
- 后台导入页：`http://你的域名/数据库/admin.html`，在页面输入 Token 后上传 Excel。

### 生产环境：Nginx 反向代理 + HTTPS

Nginx 配置示例（`/etc/nginx/sites-available/kaoyan`）：

```nginx
server {
    listen 80;
    server_name 你的域名;

    # 静态文件直接由 Nginx 提供
    root /var/www/kaoyan-site;
    index index.html;

    # 数据库 API 反向代理给 serve.py
    location /api/ {
        proxy_pass http://127.0.0.1:8767;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 管理导入接口
    location = /api/admin/import-admission {
        proxy_pass http://127.0.0.1:8767;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

启用站点并配置 HTTPS：

```bash
sudo ln -s /etc/nginx/sites-available/kaoyan /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# Let's Encrypt 免费证书
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

> 注意：Nginx 代理后，`serve.py` 看到的客户端 IP 是 127.0.0.1；
> 因此 **必须设置 `KAOYAN_ADMIN_TOKEN`**，否则后台导入接口对公网等于无鉴权。

### 进程守护：systemd

创建 `/etc/systemd/system/kaoyan.service`：

```ini
[Unit]
Description=kaoyan-site serve
After=network.target

[Service]
WorkingDirectory=/var/www/kaoyan-site
Environment=KAOYAN_ADMIN_TOKEN=你的强随机密码
ExecStart=/usr/bin/python3 serve.py 8767
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now kaoyan
sudo systemctl status kaoyan
```

## 五、数据更新流程（上线后）

1. 本地拿到最新「27考研择校宝典_录取数据表_XXXX.xlsx」。
2. 打开 `https://你的域名/数据库/admin.html`。
3. 输入 `KAOYAN_ADMIN_TOKEN`，选择 xlsx，点「导入数据库」。
4. 导入成功后自动备份原始 Excel 到 `数据库/raw/时间戳_文件名.xlsx`，并刷新 CSV。
5. 如用 MySQL，请用命令行 `python3 数据库/import_admission.py --mysql ...` 或后续扩展后台导入的 MySQL 支持。

## 六、备份

### SQLite 模式

```bash
# 每日 3 点备份数据库和原始 Excel
crontab -e
# 加入：
0 3 * * * tar -czf /backup/kaoyan-$(date +\%F).tar.gz /var/www/kaoyan-site/数据库/admission.db /var/www/kaoyan-site/数据库/raw
```

### MySQL 模式

```bash
0 3 * * * mysqldump -u root -p'密码' kaoyan_admission | gzip > /backup/kaoyan_admission-$(date +\%F).sql.gz
```

## 七、中国备案与合规

- 域名需完成 ICP 备案（阿里云 / 腾讯云均可）。
- 若使用国内服务器，未备案域名无法通过 80/443 对外提供服务。
- 站内图片、数据若涉及第三方版权，上线前再核对一次来源授权。

## 八、常见问题

| 问题 | 处理 |
|---|---|
| 后台导入返回 401 | 检查是否设置了 `KAOYAN_ADMIN_TOKEN`，并在页面输入 Token |
| MySQL 导入报 `pymysql` 未安装 | `pip install pymysql` |
| MySQL 导入报 `database is locked` | 检查是否多个导入进程同时写，重启后重试 |
| 页面刷新后数据不更新 | 服务端已发送 no-cache 头；清浏览器缓存或换无痕窗口 |
| 端口被占用 | `serve.py` 换端口，并同步改 Nginx `proxy_pass` |
