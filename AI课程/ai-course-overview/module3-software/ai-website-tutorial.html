02 · AI 辅助规划
Phase 1 · Plan Before Code

第一步：让 AI 帮你做规划

不要上来就写代码。先用自然语言把需求、页面结构、数据模型聊清楚。

你：我要做一个控制类考研择校网站。纯静态，单页应用，包含以下功能：1)顶部导航 + 搜索框 2)院校卡片列表（显示名称、地区、层次、分数线）3)按地区和层次筛选 4)点击卡片展开详情。请帮我设计页面结构、HTML骨架和院校数据的 JSON 格式。

AI 返回的页面结构

index.html 结构：
├─ <header> 导航栏 + 标题
├─ <section#search> 搜索框 + 筛选器
├─ <section#school-list> 院校卡片网格
├─ <div#detail-modal> 详情弹窗
└─ <footer> 底部信息

schools.json 结构：
[{
"name": "北京邮电大学",
"region": "北京",
"level": "211",
"scores": {"2024":345,"2025":352}
}]

高效 Prompt 公式

场景 + 技术约束 + 输出格式

// 1. 明确场景
"做考研择校网站" → AI 知道领域
// 2. 技术约束
"纯静态，单 HTML 文件" → 不引入框架
// 3. 指定输出
"给我 HTML 骨架 + JSON 格式" → 精确

核心原则：你越精确地告诉 AI 你要什么、不要什么，AI 的输出越精准。把 AI 当成一个「懂代码的实习生」—— 指令越清晰，结果越好。

好的规划是成功的一半
03 · AI 写 HTML 结构
Phase 2 · Generate Structure

第二步：让 AI 写 HTML 骨架

从导航栏到院校卡片，一步步用 prompt 生成语义化的 HTML 结构。

你：现在给我写一个 header，左边放网站标题「控制类考研择校」，右边放三个导航链接：首页、院校对比、关于。用 HTML 语义化标签。
<header class="site-header">
  <h1>控制类考研择校</h1>
  <nav>
    <a href="#">首页</a>
    <a href="#">院校对比</a>
  </nav>
</header>
你：接下来做院校卡片。每个卡片显示：校名、地区标签、985/211 标签、近两年复试线。用 section + article 标签，计划放 6-8 个卡片。
<section id="school-list">
  <article class="school-card">
    <h3>北京邮电大学</h3>
    <span class="tag">北京</span>
    <span class="tag green">211</span>
    <div>复试线: 345 / 352</div>
  </article>
</section>

HTML 编写核心原则

1 优先使用语义化标签：header / nav / section / article
2 结构先行，内容后填：先搭架子，再填充具体数据
3 每个区域独立模块：方便后续 CSS 和 JS 单独控制
4 数据与结构分离：院校数据放 JSON 文件，不硬编码

技巧：生成 HTML 后，立刻在浏览器打开看效果。如果结构不对，把页面截图发给 AI，说「这里不对，修正为 XX」比文字描述快 10 倍。

HTML 是骨架，CSS 是皮肤
04 · AI 写 CSS 样式
Phase 3 · Style with AI

第三步：用 AI 设计视觉风格

CSS 不需要从零手写 — 告诉 AI 你想要的感觉，它来写代码。

你：给这个择校网站设计配色方案：深色背景为主，卡片用暗色调，文字浅色。主色调用蓝紫色系。院校卡片 hover 时上浮 + 发光边框。要写出完整的 CSS 变量体系。
:root {
  --bg: #0f0f1a;
  --card: #1a1a2e;
  --text: #e8e8f0;
  --accent: #7c8cf8;
}
.school-card:hover {
  transform: translateY(-4px);
  box-shadow: 0 0 20px var(--accent);
}
你：页面要响应式。PC 端用 3 列卡片网格，平板 2 列，手机 1 列。导航栏手机端做成汉堡菜单。用 CSS Grid 和媒体查询实现。
.school-grid {
  display: grid;
  gap: 20px;
  grid-template-columns: repeat(3, 1fr);
}
@media (max-width: 768px) {
  .school-grid { grid-template-columns: 1fr; }
}

CSS Prompt 策略

配色 「深色 + 蓝紫，科技感」
布局 「3列网格，响应式」
动效 「hover 上浮 + 发光」
细节 「圆角 12px，间距 20px」

为什么不直接用 Tailwind？

对于学习目的，手写 CSS 能让你理解布局原理。但如果你追求效率，告诉 AI「用 Tailwind CSS CDN 引入，帮我把卡片改成 Tailwind class」即可秒切框架。

CSS 让页面从骨架变成设计
05 · AI 写 JS 交互
Phase 4 · Add Interactivity

第四步：让页面「活」起来

搜索过滤、排序切换、点击展开 — 这些交互逻辑 AI 写得比你还快。

核心 JS 功能：三个关键交互

// 1. 搜索过滤
function filterSchools(query) {
  const cards = document.querySelectorAll('.card');
  cards.forEach(card => {
    const name = card.dataset.name;
    card.style.display = name.includes(query)
      ? 'block' : 'none';
  });
}

// 2. 数据加载
fetch('schools.json')
  .then(r => r.json())
  .then(data => renderCards(data));

// 3. 详情弹窗
function showDetail(schoolId) {
  modal.classList.add('open');
  modal.innerHTML = renderDetail(schoolId);
}
你：帮我写 JS：1)页面加载时 fetch schools.json 渲染卡片 2)搜索框输入时实时过滤 3)点击卡片弹出详情弹窗。用原生 JS，不引入任何库。

JS Prompt 关键点

明确数据源 「从 schools.json 加载」
描述行为 「输入时实时过滤，不是点按钮」
技术约束 「原生 JS，不用 jQuery」
边界情况 「搜不到时显示空状态」

注意：生成 JS 后一定要在浏览器 Console 中测试。如果报错，把错误信息完整复制给 AI，它能秒定位问题。

JS 是大脑，让页面能思考

08 · 部署上线
Phase 7 · Deploy

第七步：3 分钟让网站上线

纯静态网站部署极其简单 — 没有服务器配置，没有数据库，拖拽文件夹就上线。

平台方式费用自定义域名推荐
GitHub Pages git push 即上线 免费 ✓ 最佳
Vercel 拖拽文件夹 / Git 关联 免费 ✓ 推荐
Netlify 拖拽文件夹 免费 ✓ 推荐
云服务器 Nginx + scp 上传 几十元/月 ✓ 进阶

GitHub Pages 实操

# 1. GitHub 创建仓库 zexiao-site
$ git remote add origin git@github.com:you/zexiao-site.git

# 2. 推送代码
$ git push -u origin main

# 3. Settings → Pages → 选择 main 分支 → Save
# 等 30 秒，你的网站就在线了！
✓ https://you.github.io/zexiao-site

进阶：买一个域名（约 50 元/年），在 GitHub Pages Settings 里填入域名，添加一条 CNAME 记录，你的网站就有专属网址了，就像 txkyer.cn 一样。
